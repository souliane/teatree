# Behavioral eval results

The current results page is generated from the factory's recorded scheduled local runs with `t3 eval page`. It shows the latest run date, verdict counts, cost, and failing scenarios; a run older than one week is marked STALE, and a run that graded no scenarios is marked MEASURED NOTHING.

Run `t3 eval page --out results.md` to save the current page. This repository file contains no live control-database results.
