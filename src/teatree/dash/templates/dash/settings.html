Settings

Everything this box is configured to do: the resolved model / credential / self-repair readouts below, then every config key from the schema. Sections are on the left, the selected section's rows on the right — one section is fetched at a time, so the page stays small. Edits write to the DB store; a secret value is never shown (***) and its input is write-only. Restore-to-default deletes the row. Value came from names the tier of the resolution chain that supplied the effective value (env → DB overlay scope → DB global scope → overlay code default → shipped file); shipped default shows what config/defaults.toml ships, with ✓ same as default or ● differs from default next to it.

A row in an overlay scope beats the global row for that overlay. The picker lists every registered overlay plus any scope that already holds rows.

Export

Both unticked is the delta dump: only the keys this box overrides. Default keys only restricts it to the keys config/defaults.toml ships, dropping registries, secrets, personal identifiers and overlay scopes. Include values that are the same as default also emits the keys with no DB row, at their resolved effective value. Tick BOTH and the download is a complete drop-in replacement for config/defaults.toml, header and seed tables included.
