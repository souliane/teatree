What a dump covers

Wider than the settings page: a dump carries the settings store and the loops, presets and schedules. Importing one writes them back — it can change which loops run and when — so read the preview before you apply.

Secrets and personal identifiers are withheld from an export. A complete backup including them is t3 <overlay> config_setting export --include-private, restored with config_setting import --restore-private.

Export

Both unticked is the delta dump: only what this box overrides. Default keys only restricts it to the keys config/defaults.toml ships, dropping registries, secrets, personal identifiers and overlay scopes. Include values that are the same as default also emits the keys with no DB row, at their resolved effective value. Tick BOTH and the download is a complete drop-in replacement for config/defaults.toml, header and seed tables included.
