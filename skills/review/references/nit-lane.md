# Review NIT lane

BLOCKING findings are fixed before shipping and are not posted on the PR or sent by DM. A NIT-only review does not hold: post each NIT as an inline comment, then track the set in one follow-up issue labelled `nit` and `t3-auto`. Resolve the inline threads only after reading the issue back. A NIT-ticket PR treats every finding as blocking so it cannot defer them again.

On an owner-authored PR, implement BLOCKING fixes directly, commit and push, and summarize them to the owner. Post NITs through this lane because their follow-up issue carries work left after merge.
